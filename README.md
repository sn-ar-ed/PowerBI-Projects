# 📊 Power BI Dashboard Collection

## Overview

This repository contains a collection of interactive Power BI dashboards developed to analyze data across different business domains. Each dashboard focuses on solving real-world business problems using data visualization, KPIs, slicers, and interactive reports.

---

## Dashboards Included

### 🎬 Movie Analysis Dashboard
- Analyzes movie ratings, genres, revenue, popularity, and release trends.
- Provides insights into top-performing movies and audience preferences.

### 🚗 UK Road Accidents Dashboard
- Examines accident patterns based on location, vehicle type, road conditions, and severity.
- Helps identify accident hotspots and safety trends.

### 🛒 Real Mart Sales Dashboard
- Tracks sales, profit, customer ratings, and branch performance.
- Includes product-wise, city-wise, and monthly sales analysis.

### 🍕 Pizza Order Analysis Dashboard
- Analyzes pizza sales performance, order trends, category-wise sales, and customer purchasing patterns.

### 🤖 AI Impact on Indian IT Sectors Dashboard
- Visualizes AI investment, employee growth, productivity improvements, and revenue growth across Indian IT companies.
- Provides insights into AI adoption levels and sector-wise impact.
